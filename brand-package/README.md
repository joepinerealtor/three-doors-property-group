# Three Doors Property Group - Exact-Artwork Logo Suite

Prepared for Matt Brown.

This package uses the supplied Three Doors Property Group logo as the source of truth. It does not redraw, retype, reinterpret, or substitute a different logo. The mark, typography, proportions, wording, gradients, and tagline are preserved.

The only production treatments applied are:

- removal of the supplied near-white background for transparent use;
- careful cropping of the existing artwork;
- exact extraction and rearrangement of existing logo components for the vertical layout;
- color reversal for dark-background use, with the geometry unchanged;
- one-color treatments for limited-color production;
- packaging into PNG, SVG, and EPS formats.

## File format note

The supplied master is a raster image. To follow the direction not to recreate or reinterpret the logo:

- the PNG files preserve the supplied pixels and provide transparent or background-ready versions;
- the SVG files are exact-artwork wrappers that embed those same PNG pixels;
- the EPS files embed the exact artwork on the intended white or navy production background.

This avoids the small geometry and typography changes that automatic vector tracing would introduce. If a future printer requires editable outlined vector paths, that should be handled as a separately authorized faithful-tracing project and proofed against this exact-artwork package.

## Usage

- Use the original full-color logo on white, ivory, or pale backgrounds.
- Use the packaged white-and-gold reverse logo on navy or dark photography.
- Use the Primary logo while the tagline remains readable.
- Switch directly to the Icon for profile images, favicons, app icons, and small square placements.
- Use monochrome files for embroidery, engraving, stamps, vinyl, or limited-color printing.
- Do not redraw, retype, stretch, rotate, recolor, add effects, or change the proportions.
